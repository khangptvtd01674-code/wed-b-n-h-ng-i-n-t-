III. CÁC ỨNG DỤNG JS ĐÃ ÁP DỤNG & GIẢI THÍCH CODE

1. Slider / Banner có nút điều khiển (Yêu cầu 3)

(BẠN HÃY XÓA KHUNG NÀY VÀ CHÈN ẢNH CHỤP BANNER TRANG CHỦ VÀO ĐÂY)

Đoạn code xử lý (slider.js):

let currentSlide = 0;
const slides = document.querySelectorAll('.slide');

function showSlide(index) {
    slides.forEach(slide => slide.classList.remove('active'));
    if(index >= slides.length) currentSlide = 0;
    if(index < 0) currentSlide = slides.length - 1;
    slides[currentSlide].classList.add('active');
}
function nextSlide() { currentSlide++; showSlide(currentSlide); }
setInterval(nextSlide, 5000);

Giải thích: Sử dụng setInterval gọi hàm nextSlide mỗi 5 giây để auto-play. Hàm showSlide sẽ thao tác DOM gỡ bỏ class active của ảnh cũ và thêm vào ảnh mới.

2. Form & Kiểm tra dữ liệu đăng ký (Yêu cầu 4)

(BẠN HÃY XÓA KHUNG NÀY VÀ CHÈN ẢNH CHỤP LỖI MÀU ĐỎ KHI ĐĂNG KÝ SAI VÀO ĐÂY)

Đoạn code xử lý (auth.js):

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
if(!emailRegex.test(email)) { 
    document.getElementById('errRegEmail').style.display = 'block'; 
    isValid = false; 
}

Giải thích: Sử dụng Regular Expression để ép người dùng nhập đúng email. Nếu .test(email) là false, JS sẽ đổi display thành block để hiện chữ đỏ.

3. Giỏ hàng & Local Storage (Yêu cầu 5)

(BẠN HÃY XÓA KHUNG NÀY VÀ CHÈN ẢNH CHỤP TRANG GIỎ HÀNG VÀO ĐÂY)

Đoạn code xử lý (cart.js):

window.addToCart = (productId) => {
    let cart = JSON.parse(localStorage.getItem('techzone_cart')) || [];
    const existingItem = cart.find(item => item.productId === productId);
    if (existingItem) existingItem.quantity += 1;
    else cart.push({ productId: productId, quantity: 1 });
    
    localStorage.setItem('techzone_cart', JSON.stringify(cart));
};

Giải thích: Dùng localStorage.getItem lấy dữ liệu giỏ. Dùng .find() kiểm tra trùng lặp, sau đó dùng JSON.stringify để lưu vĩnh viễn mảng vào trình duyệt.

4. Đồng hồ đếm ngược (Yêu cầu 6)

(BẠN HÃY XÓA KHUNG NÀY VÀ CHÈN ẢNH CHỤP ĐỒNG HỒ FLASH SALE VÀO ĐÂY)

Đoạn code xử lý (slider.js):

const countDownDate = new Date().getTime() + (24 * 60 * 60 * 1000);
setInterval(function() {
    const now = new Date().getTime();
    const distance = countDownDate - now;
    const hours = Math.floor((distance % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
    document.getElementById("flashHour").innerText = hours;
}, 1000);

Giải thích: Lấy timestamp hiện tại, tính thời gian còn lại (distance) và dùng phép chia lấy dư % cùng Math.floor quy đổi ra Giờ/Phút/Giây.

5. Quản lý Admin (Yêu cầu 7 Tự đề xuất)

(BẠN HÃY XÓA KHUNG NÀY VÀ CHÈN ẢNH CHỤP TRANG DASHBOARD ADMIN VÀO ĐÂY)

Đoạn code xử lý (admin.js):

window.deleteUser = (email) => {
    if (confirm("Xóa khách hàng này sẽ không thể khôi phục. Xóa?")) {
        let users = JSON.parse(localStorage.getItem('techzone_users')) || [];
        users = users.filter(u => u.email !== email);
        localStorage.setItem('techzone_users', JSON.stringify(users));
        loadAdminUsers();
    }
};

Giải thích: Hàm sử dụng confirm để xác nhận thao tác. Dùng cú pháp filter() của ES6 để loại bỏ tài khoản ra khỏi mảng mà không cần vòng lặp for, sau đó lưu lại vào LocalStorage.
